# Windows Server 2022 Quiz Reviewer

## About

This project is an offline reviewer and practice quiz for Windows Server 2022 topics, including Active Directory, DNS, server roles, administration tools, troubleshooting, backup, and security concepts.

The quiz is built as a single `index.html` file, so it can be opened directly in a browser without internet access.

The interface includes a simple DSD brand mark and footer for a clean reviewer practice layout.

## Features

- 50-question Windows Server 2022 reviewer
- Shuffled questions on every reload
- Correct and wrong answer feedback
- Score tracking
- Animated progress bar
- Smooth and clean responsive design
- DSD logo mark and footer branding
- Mobile-friendly layout for Android and Apple devices
- Fully offline-ready

## How To Use

1. Open `index.html` in any browser.
2. Choose an answer for each question.
3. Click **Next Question** to continue.
4. Review your final score at the end.
5. Reload or restart the quiz to practice again with shuffled questions.

## Offline Use

No setup is required. The project does not use external links, CDNs, images, online fonts, or internet-based scripts.

Just keep `index.html` on your device and open it anytime to review and practice.
